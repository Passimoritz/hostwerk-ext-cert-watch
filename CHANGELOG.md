## 2.1.0

- Lives where it belongs: Go live → Operate → Certificates and the dashboard tile – no own sidebar entry any more (Hostwerk 3.0+); the full page stays under Extensions → Open and can be pinned in the sidebar settings. / Steckt jetzt dort, wo sie hingehört: Livebetrieb → Betrieb → Zertifikate und Übersichtskachel – kein eigener Seitenleisten-Eintrag mehr (Hostwerk 3.0+); die ganze Seite bleibt unter Erweiterungen → Öffnen und lässt sich in den Seitenleisten-Einstellungen anheften.

## 2.0.0

- Watches any host and port with a TLS handshake – mail servers (also SMTP with STARTTLS), router, NAS, other sites; own mail servers (Stalwart, James) are added by themselves. / Überwacht beliebige Hosts und Ports per TLS-Handshake – Mailserver (auch SMTP mit STARTTLS), Router, NAS, fremde Seiten; eigene Mailserver (Stalwart, James) kommen von selbst dazu.
- Details per certificate: issuer, names (SAN), chain, key strength, trust. / Details je Zertifikat: Aussteller, Namen (SAN), Kette, Schlüsselstärke, Vertrauen.
- Thresholds “due soon” and “critical” in the settings (Settings → Notifications) instead of fixed 30/7 days; notifications and a watcher under Live → Watchers. / Schwellen „bald fällig“ und „kritisch“ in den Einstellungen (Einstellungen → Benachrichtigungen) statt fester 30/7 Tage; Benachrichtigungen und ein Wächter unter Livebetrieb → Wächter.
- Missing public domains get a “Get certificate” button. / Fehlende öffentliche Domains bekommen den Knopf „Zertifikat holen“.
- Now a native extension: page and dashboard tile drawn by Hostwerk itself, error state with “Try again”, dates in Hostwerk’s language, place in the sidebar under “System”. / Jetzt eine native Erweiterung: Seite und Kachel zeichnet Hostwerk selbst, Fehlerzustand mit „Erneut versuchen“, Datum in Hostwerk-Sprache, Platz in der Seitenleiste unter „System“.
- Service “certWatch” (list, summary) for the status page and the uptime wall; other extensions may add tabs. / Dienst „certWatch“ (list, summary) für Statusseite und Uptime-Wand; andere Erweiterungen dürfen Reiter ergänzen.
- Needs Hostwerk 2.11. Release package contains everything except the repository tooling. / Braucht Hostwerk 2.11. Release-Paket enthält alles außer dem Repo-Werkzeug.
