# Zertifikats-Wache

Alle Zertifikate auf einen Blick: wie lange sie noch gelten, welche bald ablaufen und welche öffentlichen Domains noch keines haben – mit Kachel für die Übersicht.

Eine offizielle [Hostwerk](https://github.com/Passimoritz/hostwerk-public)-Erweiterung (SDK 2.4) – Seite in der Leiste und Kachel für die Übersicht, im Design von Hostwerk, auf Deutsch und Englisch. Sie liest nur und ändert nichts.
